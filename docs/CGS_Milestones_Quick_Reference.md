# CGS milestones at a glance

**Current position** — B0 is verified. W1 is open and is the next milestone. W5 is the complete Phase 1 Wiki. P3 is the first complete tabletop release. The links open the matching deliverables and pass criteria in the [detailed milestone plan](CGS_Milestones_Delivery_Plan.md).

- **[B0 · Working foundation](CGS_Milestones_Delivery_Plan.md#b0-working-foundation)** — Already in the browser. Create basic character and place articles, link events, and inspect dated changes on the same character. This verifies the workflow. The source-designed character and place coverage is W1.
- **[W1 · Finish core worldbuilding](CGS_Milestones_Delivery_Plan.md#w1-core-worldbuilding)** — Author structured character profiles, relationships, possessions, condition, goals and beliefs. Build nested places and connections. Break down an event into expandable segments and recorded actions, including parallel branches. Inspect what changed, who was there, and what each character knew. This completes core character, place, and timeline authoring. Rule execution comes later.
- **[W2 · Author actions, powers, and rules](CGS_Milestones_Delivery_Plan.md#w2-actions-powers-and-rule-checking)** — First define the general-purpose toolbox and what it can express. Then ship browser authoring and explainable validation for prerequisites, costs, effects, progression and exceptions. The same checker must handle a power, an institutional rule and a physical limit. This finishes the Phase 1 rule authoring layer. Live execution belongs to P2.
- **[W3 · Finish the Wiki catalog and navigation](CGS_Milestones_Delivery_Plan.md#w3-full-catalog-and-discovery)** — Add the remaining world records and build browsing through articles, search, links, maps, and timelines. Check reference tasks against Fandom and World Anvil while preserving CGS’s world-state and authoring requirements. At this point manual Wiki authoring is complete. Assisted authoring, data exchange, and the release checks follow.
- **[W4 · Add assisted authoring and data exchange](CGS_Milestones_Delivery_Plan.md#w4-assisted-authoring-and-data-exchange)** — Review AI suggestions and imports before applying them, and export and restore a world with its dates and links intact. Use the ordinary browser forms when the model is unavailable. At this point the Wiki features are in place. W5 verifies the assembled release.
- **[W5 · Release the complete Phase 1 Wiki](CGS_Milestones_Delivery_Plan.md#w5-phase-1-wiki-release)** — Run the complete checklist on a dungeon world and a different setting. Verify fresh install, upgrade, recovery, access controls, and a downstream reader. This is the milestone where the Wiki is expected to meet the agreed design and authoring standard.
- **[P2 · Execute events and bounded decisions](CGS_Milestones_Delivery_Plan.md#p2-shared-event-and-decision-engine)** — Turn supported actions into rule-checked events. Verify that the same inputs produce the same effects and that an actor chooses from the information they have. Authors can try the engine in a browser test run. This is the engine finish line for the first tabletop release.
- **[P3 · Play a complete tabletop dungeon](CGS_Milestones_Delivery_Plan.md#p3-first-playable-tabletop)** — From the Wiki, prepare a dungeon and play it through in the browser. Explore, resolve an encounter, advance a character, and save and resume. Change a Wiki rule or layout and show how it changes a new run. This is the first complete playable release.
- **[S1 · Try the first story workflow](CGS_Milestones_Delivery_Plan.md#s1-first-story-workflow)** — Generate a short, sourced outline and scene from approved Wiki and play events. Review what each character and the audience can know. This is a bounded follow-on after the first tabletop release.

For each milestone, the detailed plan shows what you can try in the browser, what evidence counts as a pass, and where remaining work is scheduled. A build with unfinished checks is reported as partial even if its demo works.
